# Cyberpunk: Edgerunners — Catálogo de Personagens

Um site simples e estiloso para explorar os personagens de **Cyberpunk: Edgerunners**, com visual inspirado na estética neon do anime: fundo escuro com scanlines, cantos cortados, efeitos de glitch e a paleta amarelo `#fcee09`, ciano `#00f7ff` e magenta `#ff2a6d`.

## ✨ Funcionalidades

- 🔍 **Busca em tempo real:** filtre por nome ou cargo enquanto digita (ignora acentos) e veja quantos personagens aparecem.
- 🖼️ **Galeria em grid:** cards responsivos com imagem e cargo, cantos cortados e borda em gradiente animada no hover.
- 📄 **Página de detalhes:** idade, ocupação, status e descrição completa, com o nome "descriptografando" ao carregar.
- 🟢 **Badge de status:** ciano para vivo, magenta para morto e amarelo para os demais casos.
- ⬅️➡️ **Navegação entre personagens:** links de anterior e próximo no fim da página de detalhes.
- ⌨️ **Atalhos de teclado:** veja a tabela abaixo.
- ⚡ **Dados dinâmicos:** carregados via `fetch` a partir de arquivos JSON.
- ♿ **Acessibilidade:** cards são links reais, o foco do teclado fica visível e as animações respeitam `prefers-reduced-motion`.

## 🛠️ Tecnologias
 
- HTML, CSS e JavaScript puro (vanilla), sem frameworks ou dependências
- Fontes: **Chakra Petch** e **Space Grotesk** (Google Fonts)
