Cyberpunk: Edgerunners — Catálogo de Personagens

Um site simples e estiloso para explorar os personagens de Cyberpunk: Edgerunners, com visual inspirado na estética neon do anime (preto, amarelo 
#fcee09 e ciano 
#00f7ff).

✨ Funcionalidades

🔍 Busca em tempo real — filtre personagens pelo nome enquanto digita
🖼️ Galeria em grid — cards responsivos com imagem e cargo de cada personagem
📄 Página de detalhes — clique em um personagem para ver idade, ocupação, status e descrição completa
⚡ Dados carregados dinamicamente via fetch a partir de arquivos JSON (api/characters.json e api/characters/{id}.json)

🛠️ Tecnologias

HTML, CSS e JavaScript puro (vanilla) — sem frameworks ou dependências
Fontes: Acme, Smooch Sans e Space Grotesk (Google Fonts)
